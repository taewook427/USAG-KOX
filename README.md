# USAG-KOX v1.4.0

Universal Security Assistant Gear - Ko Extension

> Small extension modules used for project USAG

- BaseUI: 테마, 파일선택, 인메모리 뷰어 등 기본GUI 보조기능. Basic GUI functions like themes, file selection, and in-memory viewer.
- FalseCrypt: 개인 암호화 가상 파일 시스템. Personal Encrypted Virtual File System.
- IO1: 통합 입출력/채널링 인터페이스. Integrated Read/Write/Channeling Interface.
- KeyStore: WebAuthn/Android 패스키 인터페이스. WebAuthn/Android Passkey Interface.
- SVRA1: 서버 구동 보조기능. Server operation helper functions.
- TP1: 근거리 네트워크에서 데이터/zip파일을 종단간 암호화로 전송하는 프로토콜. Protocol for end-to-end encrypted transfer of data or ZIP files over a local area network.
- TP3: HTTP 네트워크에서 TLS처럼 보안 기능을 추가해주는 프로토콜. Protocol that adds security features like TLS, over HTTP network.
